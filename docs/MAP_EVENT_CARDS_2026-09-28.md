# 地图事件卡片与理解、幻灯片现状

> 本文为当天第一阶段的检查记录。随后按用户反馈移除了“另有 N 段回忆”弹窗，并接通事件/人物/照片叙述/短片更新；最新实现与验收见 [持续记忆同步](CONTINUOUS_MEMORY_SYNC_2026-09-28.md)。下列未完成项描述的是第一阶段状态。

## 本轮需求

城市故事页把日期片段和照片聚合缩略图分别绘制，数据增多后重复、遮挡，点击语义也不一致。用户要求合并显示，默认点击打开事件详情；同时询问照片理解与回忆幻灯片的实际状态。本轮不继续扩展自动专属地标制作。

## 地图修改

- 城市中的事件使用同一张卡片显示封面、日期、标题和照片数量。点击封面或文字均进入该事件详情，展示整组照片。
- 封面来自事件成员，包含没有独立 GPS 的照片；精确坐标缺失时保留城市级示意并提示位置待确认。不会因全国视图的缩放比例，把这类事件偏移到数百公里外。
- 同组照片不再额外绘制独立缩略图。全国概览仍保留城市入口和照片概览，照片避让城市入口。
- 近距离投影重叠的事件形成视觉聚合；主卡片默认打开当前显示的事件，“另有 N 段回忆”列出其他日期。仅改变展示，不合并或修改实际事件记录。缩放时重新计算聚合。
- 隐藏聚合成员的重复三维标记，并排除不可见物体的点击命中。明确关注的照片仍能定位到其实际位置，复用该事件卡片。
- 卡片避让标题区、侧栏、时间轴及精修地标。备用卡通地图也有封面与日期合并的事件卡片。
- 手机按底部对话面板计算地图可用空间，对话面板高度调整为最多 42% / 360 px。
- 沿用 liquid-glass skill：照片和地图标签使用实底内容卡片，控件面板沿用玻璃样式。

主要代码：`src/map/objects.ts`、`src/map/amapScene.ts`、`src/map/scene.ts`、`src/components/LifeMapView.tsx`、`src/App.tsx`、`src/app.css`。

## 照片理解：本机相册读取结果

以下为 2026-09-28 本轮检查时的数据，不是准确率评测：

- 62 张照片均已有单图信息卡；8 张另有跨照片线索补充结果。
- 27 个地图事件中，25 个仍为草稿及日期片段标题，1 个已分析、1 个已确认。
- 持续理解服务的 17 个事件任务中，16 个完成；1 个因无依据断言未通过校验。当前跨事件编排有 3 个创意候选。

单图分析从原图制作最长边 2560 px 的副本，取不到原图时使用预览图；照片与 EXIF/已有位置等事实一起提交 StepFun，自动队列并发为 2。返回画面描述、文字、线索、事件猜测、标签及待确认问题。画面内容、确定事实与推断需要区分，模型自行给出的置信度不是实测准确率。

这些信息用于照片卡、地点补全、主题选择，并作为人物/事件/长期故事和幻灯片编排的输入。人物的稳定身份及亲属关系另由人物匹配与用户确认维护，不能靠单张照片描述认定。

当前一个明确缺口：单图卡片、后台持续理解与原有地图事件分别保存，新的理解没有自动替换所有地图事件的日期占位标题。因此“单图信息卡完成”不代表“所有地图事件已经整理完成”。

部分既有卡片/文案仍出现超出可见证据的关系、季节或因果描述。此次为状态核对，没有批量重分析、改写用户记忆或确认这些推断。

## 回忆幻灯片：当前定位与表现

当前是照片驱动的自动回忆幻灯片：发现主题与故事候选 → 选片和顺序 → 字幕、节奏、版式 → 本地合成 MP4。身份与关系知识参与编排，修改后的内容可以触发新版本任务。

本次检查服务器保留的 8 个预览任务均为完成状态，且存在 MP4 文件；约 14–32 秒，720×960。历史导出另外保存，这个数字不是全部历史作品数量。

渲染器支持暖色相册、雪地手账、甜筒拼贴、手作、陪伴双页及细节短诗。不同模板有对应的布局、转场、运动和程序生成配乐；当前 8 个预览实际主要使用陪伴双页、暖色相册和雪地手账，不能把全部模板都算作已在这批私人照片上成功使用。

创意仍受模板集合约束，同类故事可能重复使用相近构图、节奏和结束语。既有旧片中仍存在类似“刚醒”“准备刷牙”的无依据文案；后续校验加强不等于历史 MP4 已被修正。用于比赛的版本需要选定后复查字幕。

## 验证及边界

- 构建、备用地图烟雾测试、液态玻璃规则测试通过。
- 使用本机真实相册的隔离浏览器检查：杭州 18 个事件，逐一通过卡片或聚合列表进入事件详情，照片数一致；无独立重复照片标记、无浏览器异常。全国杭州入口可正常点击，手机仍有可见事件入口。
- 隔离检查拦截账户与写入请求，没有修改真实账户数据，也没有调用真实相册的模型分析。私人截图与检查脚本只存入 Git 忽略的 `data/exports/`。
- 高德自动回归已加入卡片点击、数量、无重叠和聚合后事件可达性断言。完整流程本轮在拉取上海测试街区时遇到外部瓦片 `fetch failed`，未取得全流程通过；独立调用场景获取也复现该网络失败。
- 本轮没有将事件标题自动同步、旧片字幕修正或新的影片样式作为已完成工作。这些是后续收尾候选。
