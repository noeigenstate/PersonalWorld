# 照片区域场景恢复记录

## 本轮目标

按用户最新要求，以 `fe86d44eb007e50a4f2ddbe4b65b1b7537bf4f90` 的[武汉截图](mockups/map-scene-region-wuhan-2026-09-25.png)和[杭州截图](mockups/map-scene-region-hangzhou-2026-09-25.png)为可用的美术基准，将相同生成方式用于每组有精确定位的照片。此轮重点是通用区域的稳定性和原有材质恢复。

## 已修改

- **恢复同一渲染器。** 普通照片区域重新调用 `createStyledDistrict`，恢复窗格、檐口、屋顶、路面、树、草坪、水面反射和投影。武汉、杭州、深圳等区域没有独立美术参数；差异来自区域地理数据。东方明珠只增加已有地标模型。上一轮 `regionalMemory.ts`／`sceneRecipe.ts` 实验文件保留，但不再替代完整街区。
- **取消建筑数量对楼体生成的限制。** 原来少于 100 栋就完全不画卡通建筑；现在有可用足迹就用同样的楼体材质。少于 100 栋时只关闭大片底板及用地铺面，避免遮住 OSM 缺失而高德仍有的原生楼。原生图层只隐藏实际替换的足迹，普通照片不再放圆盘或挖圆形空地。有实际高度的楼按其高度绘制。
- **修正旧数据缓存。** 本机旧武汉缓存里多数楼高为默认 `5`，会被当成真值，造成楼体压扁。当前提取器已排除这类默认高度，服务端缓存文件加入 `v2_` 版本，避免继续读旧结果；旧文件保留。缺高度的楼继续使用基准渲染器的艺术估算。
- **修正无水地区异常。** 对空水面列表调用 Three.js `mergeGeometries` 会抛错，导致整个地区加载失败；现在正常跳过反射水面，建筑和其他地景照常显示。
- **按地理组复用。** 同组选择另一张照片、该组或其他组的信息卡更新，都不再重建街区。慢响应不能覆盖后来选中的区域；加载下一地区时保留已有场景，完整生成后再替换。场景请求有超时和可点击重试入口。
- **限制组中心漂移。** 新照片加入后，组内各照片仍须距中心不超过约 450 米，避免一长串照片逐渐拉走区域中心，导致早先照片地点落到场景范围之外。
- **修正加载时序。** 地图未完成初始化时收到的“在地图上看”请求会保留；完成后再定位。只具备城市级位置的照片不会抢占附近精确定位组。手动拖动／缩放也会触发附近组，不要求先分析照片。
- **恢复底图基准。** 默认回到截图使用的高德 `fresh` 和原有楼块色。自定义样式 ID 入口保留。

街区显示阈值仍为 zoom 16.7；相机中心约 700 米内的精确定位照片可触发约 1.8 公里的区域场景。每个组按需加载，浏览器和服务端缓存复用结果。

## 验证证据

`npm run test:amap` 走正常应用导入、照片菜单、定位、武汉／杭州区域、东方明珠、场景开关、拖动及窄视窗。它仍模拟信息卡和登录数据。

新增 `node tests/scene-regions.mjs` 启动独立 API 进程，账户文件位于临时目录，实际注册一个测试账户，使用真实 `/api/map-scene`、真实高德代理和公开坐标。除刻意制造一次 503 和延迟一次响应外，成功响应直接来自真实服务端。它不读取用户的账户文件或照片，不调用 StepFun 分析私人内容。

该测试验证：初始化前定位、同组照片切换不重新请求／生成、卡片更新不重建、缩小后放大恢复、开关恢复、晚到响应不覆盖当前场景、失败后重试，以及稀疏足迹和无水面输入。一次完整运行结果：

| 公开样本 | 实际生成楼体 | 结果 |
|---|---:|---|
| 武汉 | 654 | 完整街区材质 |
| 杭州 | 553 | 完整街区材质，无需照片主题 |
| 湘潭 | 20 | 使用相同窗格材质，保留未替换的原生楼 |
| 深圳 | 832 | 同一生成器处理高楼区域 |

稀疏合成样本只有 1 栋、没有水面：窗格正常生成，已知楼高 226 米保持不变，只隐藏该足迹，不铺大片底板。全部检查通过，浏览器运行时错误和 Three.js 着色器错误均为零。

## 仍有的边界

这次已将同一生成路径接到所有精确定位照片组；没有任何城市白名单，也不由照片主题决定是否显示材质。**地理数据覆盖不足的地点，仍会有未替换的高德楼块。** 现有开放数据不能保证每栋楼都有轮廓和准确高度，程序不会为缺失楼体编造位置。仅定位到城市／省份的照片仍需更精确的位置才能生成街区。

以上是公开样本和真实接口的验证。工具未连接到用户已有的浏览器，故未宣称逐一验收过其 IndexedDB 内全部私人照片组。当前照片组会在原页面刷新后按自身坐标进入同一流程。可通过地图容器的 `data-scene-state`、`data-scene-buildings`、`data-scene-surfaces` 和 `data-scene-builds` 查看加载状态、已生成楼数、铺面模式及生成次数，不需导出私人照片。
