# 常去地点、持续理解与回忆幻灯片更新

## 需求与本轮边界

本轮承接 `MAP_EVENT_CARDS_2026-09-28.md` 的第一阶段。用户要求：同一地点的不同日期回忆在一张地图标签里直接排列；使用已保存的人物身份及关系；建立理解结果到事件、照片卡及短片的动态更新机制；增加照片幻灯片的叙事和视觉变化。没有扩展任意地标建模，也没有修改既有三维资产。

## 地图：地点卡片里直接选择每次回忆

- 卡片中每行有自己的照片、日期、标题和照片数，点击这一行进入这一事件详情。
- 移除“另有 N 段回忆”及其二次弹窗。常见三次回访直接看到三行；更多记录在卡片内部滚动，滚动不会同时缩放地图。
- 相同 AOI/POI 名称、都有坐标且相距不足 1.5 公里的记录优先作为同一地点展示；不把省市区或道路名称当作同一个场所。屏幕上太密集的其他地点仍可收拢，标题明确写“附近的回忆”。
- 数据中的各次事件保留独立 ID，没有合并相册或日期。当前关注的照片仍定位到它自己的位置。
- 卡片避让地图标题、对话面板和时间轴。手机版保留内部滚动。

## 修复的同步断点

### 1. 两套事件缺少对应关系

原地图按导入分组保存事件，图谱又按时间/地点重新分组。后台完成了图谱章节理解，但地图无法可靠找到对应结果。

现在有原始事件时，图谱按其稳定 ID 建立来源关系 `sourceEventId`；没有来源事件的照片仍可自行分组。单张照片事件同样参与理解。当前有效结果经 `understoodEvents` 投影到地图、时间轴、待整理列表、详情页和管家的事件输入。

自动叙述没有写回原始 `memory.events`。这是为了保留用户编辑，并避免“AI 输出成为新事实、又触发下一次 AI”的循环。用户确认的事件标题和摘要保留，新增理解在详情中另行展示；未确认事件可以使用当前有效理解的标题、摘要和人物名字。

### 2. “与你的关系”没有形成关系边

人物界面允许填写“我”“女儿”“妻子”，原解析器只支持“某某的姥姥”。现在，当且仅当存在一个确认过且标记为“我/本人/自己”的身份时，将直接亲属称呼关联到此人。

撤回“我”的标记会撤回相应的相对关系；存在两个“我”时不猜选；明确写了姓名的关系继续支持改名后保留 ID 关联。这里没有凭照片外观新建亲属关系，也没有更改人脸检测或匹配阈值。

### 3. 理解已完成，但短片没有收到变化

旧刷新依赖人物库的外层 revision，而持续理解改变的是图谱 revision。现在两者都能使短片重新读取当前依赖。

事件理解新增按照片 ID 对应的 `photos` 叙述。照片卡顶部使用其最新标题与说明，原始视觉观察保留；短片收到同一份 `narrative` 作为参考。它仍是解释，不会冒充用户确认事实。人物存在范围按每张照片匹配结果核对。

`filmKnowledgeRevision` 包含实际逐图叙述内容。开启自动生成时，相关作品进入原有有界更新队列，连续修改仍合并等待；暂停继续有效。上传阶段再次检查资料，变化则重新编排，旧 MP4 不原地覆盖。

## 持续更新的行为

1. 导入/修改照片信息或事件资料后，浏览器防抖同步原始资料。
2. 人物改名、关系确认或人脸关联修改立即更新图谱来源。
3. 队列比较受影响输入的指纹，只重新理解变化的事件，再更新跨事件故事。
4. 旧请求结果不允许发布到新输入版本；页面轮询不能覆盖更新中的人物修改。
5. 当前有效叙述同步到地图事件、单图说明、人物与故事及短片依赖。

原有持久队列、失败显示、显式重试和暂停机制保留。对本次发现的事实校验错误升级提供一次恢复尝试，不循环重试失败输入。校验错误现在说明具体缺乏依据的称谓/断言；观察中出现的“亲子活动中心”类场所名与人物关系断言分开处理。

单图队列也检查关键观察是否为空，不能仅凭 `card` 对象存在就标记完成。旧卡片缺少 `scene` 时自动补分析；接口拒绝仍无观察的响应，保留旧卡并暂停队列，避免无限调用。

## 幻灯片的可执行创意

版本：导演 `memory-film-7`，合成器 `creative-scenes-6`。

- `compare`：从较早的已选镜头选择有共同人物、地点或主题依据的一张，做双格回看；两格各标自己的日期。
- `ribbon`：当前照片与前两张组成接触印样，主体照片较大，其他片刻保留作回看。
- 书页、甜筒、沙地、雪地、手工作为观察支持的装饰主题；不是随机贴图。
- 镜头支持淡入、翻页、直接切换；原有六种主题、美术、配乐与整张原片保护仍保留。
- 开场显示实际入选照片中已确认人物的名字，避免模型始终省略称谓后成片仍像陌生人的相册。
- 模型使用最新人物资料、逐图叙述和创意方向。已确认关系不会被旧视觉猜测覆盖，未知同框者继续保持未知。

这些仍是原照片合成的回忆幻灯片，不是生成实拍运动视频；原始视频理解仍在长期计划中。

## 尚需注意的实际边界

- 输入的单图观察仍可能识别错误；人物修订不能凭空修复未匹配人脸。此轮没有声称人脸识别达到全覆盖。
- 事件超过 28 张时，持续理解沿用抽样上限；没有得到逐图新说明的照片继续保留原卡片。用户事实优先。
- 地图场景依赖外部数据，完整高德街区回归上一阶段受到外部瓦片请求失败影响；本轮地图入口检查不能代替所有街区的三维验收。
- 暂停自动短片时资料仍可更新，但不会擅自重新导出。现有队列维护保留中的作品，已过期的全部历史 MP4 并没有永久依赖登记。
- 创意有了更多编排手法，仍受到照片数量、原始画面与模板词汇的限制；不把已完成数量当作理解准确率。
