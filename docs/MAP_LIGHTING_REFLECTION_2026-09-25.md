# 上海街区场景：光照、河面与草坪试作

2026-09-25。对照[美术概念图](mockups/map-style-direction-2026-09-25.png)和[此前网页画面](mockups/map-scene-after-reference-study-2026-09-25.png)，本轮把最显眼的平面感先压下去。[当前桌面实测](mockups/map-scene-lighting-reflection-2026-09-25.png)与[手机宽度实测](mockups/map-scene-lighting-reflection-mobile-2026-09-25.png)来自真实高德底图与浏览器渲染，不是生成图。

## 已接入

- `src/map/styledDistrict.ts` 用 Three.js `Reflector` 将同一 3D 场景里的楼体、树和东方明珠投到黄浦江面；河水着色器将倒影与蓝绿色水体、短碎波光混合。反射纹理桌面 768²、窄屏 384²，并取消多重采样以控制额外渲染开销。
- `src/map/amapScene.ts` 使用一盏定向光和阴影贴图。街区建筑、树与地点小景投影；透明接影层覆盖道路、草地和水面。移除了先前与真实楼高无关的平移轮廓阴影。阴影只在进入场景或重建场景后更新，避免每次地图移动都重新生成。
- 草地从单层色块改成连续的宽窄两级颜色噪声、细小草叶高光，以及固定种子的低矮草丛几何。草丛避开建筑、水域和道路。楼体与屋顶也能接收邻近楼体的投影。

## 对照概念图的差距

这版改善了空间感，但还不是概念图的完整还原。楼体与树的形状仍依赖有限的 OSM 轮廓和程序化装饰；窗、屋顶和草地的局部丰富度低于概念图。河面只反射我们自己的 Three.js 场景，**不能反射另一张高德 WebGL 画布**里的原生楼宇与天空。高德底图的天空、非样本街区和道路仍采用官方 `fresh` 样式；要统一全图调色，需要发布可用的高德自定义样式 ID，再做浏览器实测。

当前只在东方明珠周围的上海样本接入。其他华东地点仍显示已有的记忆小景，不能把上海建筑或草坪推断到其他真实地点。

## 验证

`npm run build` 与 `npm run test:amap` 通过。后者覆盖上海样例入口、离开并返回街区缩放、照片聚焦、3D 开关、拖动和 390 像素窄屏截图。反射需要额外一次场景绘制，阴影需要贴图；测试只验证当前桌面 Chrome 的可用性，尚未覆盖不同手机 GPU 的帧率。
