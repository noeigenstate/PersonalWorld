# 可辨认的卡通地标精修

把真实建筑的识别特征做成可复用、可验证的代码资产。保持已有完整街区和统一美术。运行时根据已确认的建筑 ID 加载资产；新地标要经过参考分析、建模和验收，不能宣称任意照片会即时生成精确建筑。

**能力边界**：可以固化资料收集、形态分析、生成代码与验收的流程；这不等于任意地点已经具有同品质的运行时自动建模服务。独特屋盖、场馆结构与立面仍依赖足迹/方位、多角度参考、资产制作和视觉验收。没有这些材料时保持真实地图与通用场景，并在区域清单告知待精修，不伪造“全部完成”。

无独特地标的地点，先完善实际建筑、水系和绿地的统一场景类型。`venueArchitecture.ts` 的商业体外观属于通用商业建筑语言；有注册 ID 的 `landmarkVenues.ts` 模型才属于已核实的特殊建筑精修。不要用同一通用造型冒充每处地标。

从当前 Git、`src/map/landmarkVenues.ts`、`styledDistrict.ts` 和实际截图判断已有能力，保留用户已认可的效果。地图坐标及叠加规则见 [amap-threejs](../amap-threejs/SKILL.md)，街区规则见 [map-scene-styling](../map-scene-styling/SKILL.md)。新增或大改资产前读[工作流程与拱墅实例](references/workflow.md)。

## 输入与产物

- **地理依据**：准确地标身份、OSM 建筑 ID、真实建筑足迹与方位，已有楼高和相邻场地。公园边界与建筑边界分别保留。
- **形态依据**：优先设计方、场馆方的多角度实景、平面、立面和结构示意。至少能确认整体轮廓及主朝向；照片不足时降低精度承诺，不用通用球顶冒充专属精修。
- **美术依据**：项目已验收的地图/模型截图、统一色板、光照、材质和性能范围。
- **输出**：程序化模型、准确建筑 ID 注册、参考来源和估算项、多视角检视、真实地图近景及完整地点截图。复用现有通用模型作为未覆盖建筑的回退。

## 执行要求

1. 找出决定辨认度的 3–5 个特征：大轮廓、屋顶走势、开口/支撑关系、主要立面节奏、相邻场地朝向。先确认这些，再做小装饰。
2. 沿真实足迹建模，缩至建筑中心附近计算几何，再平移回地图。项目 x 东、y 北、z 上；固定地理尺度，旋转/缩放地图时建筑不漂移、不跟随镜头改变体积。
3. 按轮廓与体量 → 屋盖/结构 → 立面节奏 → 材质 → 地图整合逐层推进。轮廓不对时不靠增加窗户或贴图掩饰。卡通化可统一细节、加厚结构、简化曲面，保留特征比例、真实朝向和地理关系。
4. 相似构件保持一致；复用几何/材质、合并或实例化重复部件。沿用现有场景灯光与阴影，先在地图环境校色，避免为单馆调整全局渲染导致街区倒退。
5. 只给有依据的建筑 ID 注册专属模型。地图仅记录为点的灯塔等地标，可用核实后的公共点位注册，另记估算的建筑足迹、尺寸和来源；不能依赖照片必须拍到它。照片组复用地点场景；不得用圆形底盘、整块地面或主题贴图盖住原建筑、水面、道路，也不得按城市名称替换整片街区。
6. 每次实际观察模型的俯视、正面、背面、斜视及地图近景。检查顶面法线、支撑落地、开口方向、阴影、照片点击和湖河保留。模型检视台通过后仍必须检查真实地图；构建通过不能代替视觉验收。

## 验收与说明

执行 `npm run build`、`npm run test:venues`，将新增地标纳入该测试的真实轮廓和多视角样例。再用 `tests/scene-region-preview.mjs` 检查对应坐标的真实地图；涉及共享边界/地理管线时才扩展 `tests/scene-regions.mjs`。报告实际三角形数、绘制调用和测试镜头，区分模型检视台与整个街区开销。

交付时说明用了哪些资料、哪些几何为艺术估算、哪些建筑 ID 已覆盖；附实际截图。概念画不能作为运行结果。第三方照片只作参考，未经授权不打包成纹理。私人照片、凭据和临时参考资料留在 Git 忽略目录。

新增地标库与本轮实测见 [2026-09-27 多地点扩展](../../../docs/PLACE_EXPANSION_2026-09-27.md)。`landmarkSites.json` 保存公共身份、足迹和来源，`mapLandmarks.mjs` 补充地图资料中遗漏的点地标并处理旧瓦片重叠，`publicLandmarks.ts` 生成资产。量化后的瓦片顶点可能全部落在真实轮廓外侧；应按多边形交叠面积识别重复楼体与瓦片碎片，不能只数相交顶点。塔楼不能删除相邻的大裙房。检查倒角是否吞掉窗、檐口等立面细节；相机取景应包含地标顶端，照片和说明卡应避让地标。额外执行 `node tests/landmark-expansion.mjs`。
