# 回忆讲述配对试验

输入为四条**虚构的积木照片观察**和确认的母女关系，不含私人照片。真实响应见 [results.json](results.json)，当时的指令快照见 [skill-used.md](skill-used.md)，复现入口为 `node skills/memory-storytelling/evals/run.mjs`。

本次是 v6 文字证据流程，模型为 `step-5-preview`，推理强度 medium。基线使用普通“依据资料写温暖回忆”的指令；skill 组运行选题、写作与独立复核流程。因此这是整套流程的样例比较，并非等调用次数的纯提示词实验，也不是成功率测试。后续运行时已增加选片实图复核及模型分工，此样例不包含这些新增环节。

## 逐条核对结果

| 项目 | 普通指令 | 运行时 skill |
|---|---|---|
| 结构 | 四张图各一段 | 以黄色积木为联系，有跨图和留白 |
| 个人事实 | 写出“学搭积木”“三月已经能自己坐”“我不再需要扶”等未给出的能力变化 | 没有把月份跨度说成长大、学会或独立能力 |
| 未记录情节 | 添加倒塌声音、谁碰倒、家长内心和拍摄之外的等待 | 复核删去松紧比较、固定偏好及“同一块”物品假设 |
| 仍需改进 | 有故事语气，但以虚构补充了因果 | 个别句子仍偏描述；“她只管守住自己的颜色”带有拟人解读，不能当成孩子的真实意图 |

只验证了一个文字证据样例。不能据此说能自动准确理解任意家庭相册，也不能用模型自报的复核通过代替人类观看。私人素材调试还遇到过空 JSON、格式漂移和超时，记录在项目实施文档中；接口稳定性和内容质量需要分开验收。
