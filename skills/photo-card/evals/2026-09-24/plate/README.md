# 车牌照片评测 · 2026-09-24

## 起因

用户导入的富士相机原图没有 GPS。其中一张（DSCF3348，雨天透过挡风玻璃拍前车）生成信息卡时，模型把车牌读成"云A 12345"，推断"拍摄于云南"，把握 70%，还把"云南"写进了标签。同一张照片的事件分析读成"藏A"。

## 真实答案

把原图 1:1 裁出车牌放大 4 倍：首字（省份简称）隔着雨水、失焦，**无法辨认**。唯一正确的写法是"?A 12345"。

开发过程中我曾根据高原风景把它读成"青A"，这同样是猜测，已更正。

## 方法

真实 StepFun `step-3.7-flash`，每个组合 3 次：

- skill：`before`（加规则前，`SKILL.before.md`）/ `after`（加入"看不清写 ?、车牌不作 placeQuery"后）
- 图片：`1200`（应用存的预览）/ `2560`（从原图重新生成，应用生成信息卡时实际发送的）

两种评分：模型原始输出，以及经过 `server/photoCard.mjs` 之后**应用实际显示**的结果。"因车牌定位"指：车牌线索把握 > 0.3，或标题、描述、标签、地图搜索词里出现只由车牌推出的地名。

## 结果

| 组合 | 模型读出的首字 | 模型写"?" | 模型因车牌定位 | 应用显示时因车牌定位 |
|---|---|---|---|---|
| before-1200 | 浙 鄂 苏 | 0/3 | 3/3 | 0/3 |
| before-2560 | 苏 鲁 鄂 | 0/3 | 3/3 | 0/3 |
| after-1200 | 川 浙 鄂 | 0/3 | 3/3 | 0/3 |
| after-2560 | 鲁 鲁 鲁 | 0/3 | 3/3 | 0/3 |

## 结论

- **模型改不过来**：12 次都自信地读出一个省份，换高清图、加规则都没用。它看不清，但不知道自己看不清。
- **靠程序兜底**：`server/photoCard.mjs` 把任何点出地名的车牌线索降到 0.3，并删去标题、描述、标签、地图搜索中只由车牌得出的地名。兜底第一版漏了 3 次（线索被归为"物品"、标签写成"武汉车牌"、删字后留半句），修正后 12/12 全部拦住。这几种情况已写入 `skills/photo-card/test.mjs`。
- 地点仍按"照片自带信息 → 画面中的地标和地名 → 其他照片"的顺序确定，车牌不参与。

## 复现

```bash
node skills/photo-card/evals/2026-09-24/plate/run-eval.mjs            # 12 次真实调用，需要 plate-*.jpg
node skills/photo-card/evals/2026-09-24/plate/run-eval.mjs --regrade  # 只重新评分（results.json 含照片中的车牌号，只保存在本地）
```
